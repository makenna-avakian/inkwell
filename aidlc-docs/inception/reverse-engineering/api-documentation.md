# API Documentation

## REST APIs

None. No Route Handlers or Server Actions exist in `shareart-frontend`, and `shareart-backend` has no code.

## Internal APIs

None — no shared interfaces/classes beyond React components.

## Data Models

None — all data (the artwork list on the Gallery page) is a hard-coded in-file array (`src/app/gallery/page.tsx`), not a data model backed by any schema or store.
